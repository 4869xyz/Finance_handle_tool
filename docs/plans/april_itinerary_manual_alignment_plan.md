# 四月高德行程识别对齐计划

## 需求背景

以四月自动识别与人工校正 Excel 为语义黄金集，优先修复 9 份高德打车电子行程单的「行程起点 / 行程终点 / 行程时间」。根因是 PDF 跨行起终点在纯文本层丢失列关系，且标题被误解析为起终点。

## 已确认口径

- 多行程展示：逐段对应，起点/终点/时间均按段用 / 拼接（保留重复地点）。
- 单行程时间：页首行程时间完整范围 YYYY-MM-DD HH:MM至YYYY-MM-DD HH:MM。
- 多行程时间：只展示各段表格明确开始时间（含日期），不编造单段结束时间。
- 人工表换行与明显缺括号（如立道终点）按语义对齐，不字面复制。
