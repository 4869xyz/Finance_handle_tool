# docs/plans/

功能计划书目录（Cursor Plan / Agent 工作流）。

## 约定

- 一个功能一个文件：`{Feature}_plan.md`
- Plan 模式只维护本目录文件，确认前不改业务代码
- Agent 模式严格按该 plan 的 Checklist 执行并勾选

## 模板

见 `docs/Cursor项目规范使用流程.md` 末尾「Plan 文件建议模板」。
